# birthdaymath

An interactive birthday letter for **Dr. Renu Nagpal**.

Four small questions spell **RENU**. Then a long letter.

Built by **Manan Bharti** (CSE B · 126030115) and **Rehaan Gulbhadar** (CSE B · 126030062) — Diploma Computer Science, Thapar Institute.

**Live:** [hbdrenumam.vercel.app](https://hbdrenumam.vercel.app)

## Stack

- TypeScript · React · Vite
- Deployed on Vercel from the `main` branch

## Edit the letter

Content lives in `src/content/teacher.ts`.

## Local run

```bash
git clone https://github.com/BiasManan2010/birthdaymath.git
cd birthdaymath
npm install
npm run dev
```

## Deploy

Deploy **Vercel from `main`**. Do not set the production branch to `gh-pages` — that folder is only built files, so `npm run build` fails there.
